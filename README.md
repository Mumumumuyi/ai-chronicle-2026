# 火种、严冬与硅基奇点：人工智能演进全景通史 (1943 — 2026.09.13)

本项目是一个集**深度学术写作**与**高质感液态玻璃交互体验**于一体的人工智能发展全景通史互动系统。

- **时间跨度**：1943 年（M-P 神经元模型）至 2026 年 9 月 13 日（当前时刻：系统二推理、测试时计算缩放定律、自主 Agent 闭环与神经符号大收敛）。
- **学术深度**：包含约 1.8 万字的全景专著通论（序章与六大纪元），兼具形而上哲学审视、算法数理演变、工程算力跃迁与地缘科技博弈。
- **美学规范**：融合世界级数字出版物标准（Awwwards / Stripe Press / Linear），采用液态玻璃（Liquid Glass）双层微描边、黑曜石暗调灰阶、高信息密度 Bento 架构与瑞士工匠排版。

---

## 核心交互功能

1. **时空编年剧场 (Liquid Epoch Stage)**：
   - 7 大历史纪元（从黎明破晓至自主智能体集群）无缝横向跳跃与键盘快捷切换 `[← / →]`。
   - 4 栏历史元指标 Bento 面板（时间跨度、断代纪元、算力扩张指数、当代核心范式）。
   - 各纪元核心里程碑档案库（Dossier），支持调阅关键奠基人、算力消耗与经典文献索引。

2. **范式与算力实验室 (Paradigm & Scaling Lab)**：
   - **测试时计算（Test-Time Compute）第二缩放定律推演仪**：支持调节思考 Token 预算与基座参数规模，实时动态投射 MATH-500、SWE-bench Verified 与 GPQA Diamond 基准跃迁。
   - **五大历史范式全维对比矩阵**：符号主义、连接主义、统计学习、大语言模型与自主智能体的认知架构横向对照。

3. **通史长卷精读 (Treatise Reader)**：
   - 1.8 万字专著级排版与实时目录导航（ScrollSpy TOC），带阅读进度指示器。
   - 核心时代箴言与原始文献典籍索引。
   - 支持 BibTeX / 学术论文一键引用与学术 PDF 打印导出。

4. **前沿生态与商业特权 (Ecosystem & Compute Perks)**：
   - 严选前沿 GPU 云算力（H100 / A100 / RTX 4090）、AI 编程 IDE、高速推理 API 与多模态创作工具。
   - 商业化合作申请与自主品牌赞助接入通道。
