# 火种、严冬与硅基奇点：人工智能演进全景通史 (1943 — 2026.09.13)

本项目是一个集**深度学术写作能力**与**高质感前端可交互 UI 体验**于一体的人工智能发展通史互动系统。

- **时间跨度**：1943 年（M-P 神经元模型）至 2026 年 9 月 13 日（当前时刻：系统二推理、测试时计算缩放定律、自主 Agent 运行回路与神经符号大收敛）。
- **学术深度**：包含约 1.8 万字的全景专著通论（序章与六大纪元），兼具形而上哲学审视、算法数理演变、工程算力跃迁与地缘科技博弈。
- **美学规范**：深度践行本机 **AI 第二大脑**（`AI-第二大脑/`）沉淀的《UI设计反AI味基准》与高质感瑞士工匠排版标准。

---

## 核心交互功能

1. **时空编年全景 (Timeline View)**：
   - 7 大历史纪元（从黎明破晓至自主智能体集群）无缝横向/纵向跳跃。
   - 范式（符号主义、连接主义、统计学习、深度模型、Agent系统）与分类多维筛选。
   - 毫秒级全局关键词搜索（人物、论文、硬件、算力）。
   - 单击任意卡片调阅详尽的**历史绝密档案 (Deep Dossier)**。

2. **通史长卷精读 (Treatise Reader)**：
   - 专著级版式与实时目录导航（ScrollSpy TOC），带阅读进度指示器。
   - 核心洞见（Historiographical Insight）与原始文献典籍索引。
   - 字号调节与一键引用功能。

3. **范式与算力实验室 (Paradigm & Scaling Lab)**：
   - **实验 A**：系统二测试时计算（Test-Time Compute）第二缩放定律模拟器，实时对比直觉生成与思维链树搜索的准确率、延迟与 FLOPs。
   - **实验 B**：五大历史范式（符号、连接、统计、LLM、2026 Agent）全维对比矩阵。
   - **实验 C**：算力爆炸对数标尺（从 1950 年的 10^3 FLOPs 拖动到 2026 年的 10^27 FLOPs）。

4. **AI 第二大脑知识映射 (Second Brain Hub)**：
   - **动态对比视窗**：一键切换体验“AI 味套路界面”与“专业反 AI 味界面”的质感差异。
   - **Agent Runtime Loop**：可视化拆解现代自主执行回路（目标编译 → 方案图 → 验证引擎 → 返工引擎 → 最终裁决）。
   - **原子知识网络**：联动本机 Obsidian Vault 中的 560+ 篇知识笔记。
